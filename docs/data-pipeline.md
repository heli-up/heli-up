# 三条 APP 三阶段数据生成管线

在北京陌陌科技有限公司三条 APP 数据集组中，参与面向用户画像推断的数据集构建。工作覆盖标签体系、生成管线、多模型评估和人工校准。

## 从生成内容到可用数据

单阶段 Prompt 难以分别控制场景设定、对话内容和画像结果。管线将这三项任务拆开，并引入画像细化与校验环节，使每个阶段都有明确产物和检查入口。

```text
标签体系与约束
      │
      ▼
  场景生成 → 对话生成 → 画像生成
                         │
                         ▼
                 ProfileRefinement
                         │
                         ▼
                    Validation
                         │
                         ▼
                    人工二审校准
```

## 我的工作与产出

| 环节 | 工作内容 |
| :--- | :--- |
| 标签体系 | 设计 5 层级、700+ 节点标签库，覆盖 12 个画像维度，经历 4 轮迭代 |
| 生成流程 | 编写结构化 Prompt，调用多模型 API，搭建“场景 → 对话 → 画像”管线 |
| 质量控制 | 引入 ProfileRefinement 与 Validation，并对生成样本进行人工二审 |
| 对比评估 | 开展多模型对比与消融实验；3 款模型分别生成中英文各 100 条数据 |
| 最终产出 | 600+ 条标注样本及可复用生成管线 |
